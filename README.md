# Authorship Forensic

A cybersecurity and machine learning project focused on detecting and classifying AI-generated versus human-written text using Statistical Natural Language Processing (SNLP) and deep learning techniques.

This project combines authorship attribution, natural language processing, and machine learning to analyze writing patterns, linguistic structures, and textual characteristics for forensic-style text classification.

---

# 📌 Project Overview

The rise of generative AI systems has created new challenges in authorship verification, academic integrity, misinformation detection, and cybersecurity investigations. This project was designed to explore how machine learning models can distinguish between human-authored and AI-generated content.

The system analyzes submitted text and predicts whether the content was written by a human or generated by AI models such as ChatGPT.

# 🔍 System Workflow

1. User submits text input
2. Text preprocessing and normalization occur
3. NLP feature extraction is performed
4. Machine learning model analyzes writing patterns
5. System predicts:
   - Human-written
   - AI-generated
6. Confidence score and results are displayed
